# Aerostratospheric Fixed Weather Station KILCASEY47

Fixed station **KILCASEY47** (Aerostratospheric), Casey, Illinois.
Same coordinates as NASA GLOBE site 422147.

Do not use KILCASEY32 — that is a neighboring station.

Collection runs from the ground station workflow in this repository and needs its API key repository secret.

Licence: not yet specified for this layer; credit Aerostratospheric Fixed Weather Station KILCASEY47.

Station data is provided to NOAA through the Citizen Weather Observer Program (CWOP) via KE9CFY.
